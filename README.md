# bun-wasm

Bun's Rust toolchain compiled to WebAssembly, with a Bun-compatible runtime: run JS apps, client and server, in a browser tab.

## Quick start

Open the [playground](https://bun.sprockt.dev/playground/) and press **Run**.
The guest loads in the tab, so there is nothing to install.

```console
user@bun:~$ bun run 'index.ts'
Hello, world.
Hello, Bun!
Hello, WebAssembly.
```
