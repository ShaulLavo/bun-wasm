# Internal working notes

These files are working notes, not user documentation: plans, a spike report, measurement dumps, dated acceptance and publication records, and investigation notes. Nothing in the README or `docs/` links here. Paths inside them (`/work/...`, relative links to `docs/`) record where the work happened and can be stale. An item leaves this directory in one of three ways: a finished plan becomes an ADR in `docs/adr/` or a public page, a number worth citing moves into a public page together with the command that reproduces it, or the item is deleted (git history keeps it).
