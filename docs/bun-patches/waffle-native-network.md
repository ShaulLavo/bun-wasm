The retained `network/LICENSE` is Waffle's MIT license and copyright notice.

The host build checks both records and the actual module bytes, then copies the
triplet into `OUT_DIR/waffle-network`. The launcher embeds those bytes. A native
build needs no prepared JavaScript dependency directory. The launcher never reads
`node_modules`, compiles a network guest, or downloads a module at runtime.

Waffle owns OS sockets, native readiness, TCP state, transport queues, and private
accepted drains. Bun owns opaque public handles, address policy, error JSON,
notifications, and deadlines. Each Net owns a fresh module instance and one joined
actor. Other threads send commands before waking the actor. Every import borrows
that instance's current memory separately from Bun guest memory.

The five-second private retirement deadline is Bun policy. Normal exit waits up
to two seconds for admitted output, not peer EOF. Disposal wakes the OS wait,
releases Waffle resources, and joins the actor. Async fetch keeps its separate
Tokio transport. The old `net/tcp.rs` source remains unselected pending consumer
acceptance. There is no backend fallback or version negotiation.

The reserved Node WASI caller block is unchanged by this adapter. Slot tests
exercise the Wasmtime bindings and numeric errors directly. They do not establish
that a newly qualified Bun guest has passed product-level native acceptance.

Hostname resolution currently runs synchronously in the Bun facade and selects
the first resolved address. This differs from the retained threaded dialer.
Cancellable resolution and candidate selection remain a native activation
blocker. No fallback selects the old transport.

Two unignored consumer regressions record that hold:
`native_connect_preserves_candidate_failover_policy` and
`native_connect_allows_cancellation_while_lookup_is_pending`. Their lookup input
is controlled only in test builds. They do not add a production resolver or
transport. The candidate is not merge-ready while those tests fail.
