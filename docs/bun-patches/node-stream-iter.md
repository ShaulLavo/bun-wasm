## Node `stream/iter` experimental builtin

Class **Port** (generated builtin factories) and **Host feature** (flag gating and runtime-provided internal adapters).

Bun ships the experimental `node:stream/iter` module behind `--experimental-stream-iter` (`src/js/node/stream.iter.ts` and `src/js/internal/streams/iter/*.ts` at Bun `a7733435cf40429e3b35c36072769df2052b80f1`). bun-wasm now bundles those generated factories through the existing [builtin loader](builtin-loader-adapter.md) (`crates/bunwasm-runtime/generated/builtins/91.js` to `99.js`, `101.js`, `102.js`, and `178.js`) and parses `--experimental-stream-iter` explicitly in `crates/bunwasm-cli/src/main.rs` into `Options::experimental_stream_iter`, gating both Rust module resolution (`crates/bunwasm-runtime/src/resolve.rs`, `lib.rs`, `split.rs`, `engine_host.rs`, `hot_run.rs`, `import_requests.rs`) and JS builtin registration (`crates/bunwasm-runtime/src/js/builtins.js` via `native.experimentalStreamIter()`). Values passed to other options (such as `--conditions --experimental-stream-iter`) and trailing script arguments do not enable it.

When `--experimental-stream-iter` is absent, `node:stream/iter` and `stream/iter` are not resolved as builtins and are not registered in `builtinFactories`, so `require.resolve.paths("stream/iter")` returns the normal module search paths instead of `null` (`crates/bunwasm-runtime/src/js/bootstrap.js`, after validating that the request argument is a string with `ERR_INVALID_ARG_TYPE`). Matching Bun's `isBuiltinModule.cpp`, `module.isBuiltin("stream/iter")` and `module.isBuiltin("node:stream/iter")` remain `false` and `module.builtinModules` omits `"stream/iter"` even when the flag is enabled. When enabled, loading `node:stream/iter` runs Bun's unchanged `src/js/node/stream.iter.ts`, which emits the `ExperimentalWarning`.

The `streams/iter` modules import seven internal Node modules (`internal:errors`, `internal:validators`, `internal:streams/add-abort-signal`, `internal:streams/destroy`, `internal:streams/end-of-stream`, `internal:streams/readable`, and `internal:streams/writable`). Rather than embedding a second copy of Bun's internal Node streams stack, `scripts/bun-builtins.json` lists them under `runtimeProvided` and `crates/bunwasm-runtime/src/js/bun_provided_internals.ts` adapts them onto bun-wasm's existing `node_stream_core` and `node:stream` classes (including forwarding `internal:streams/destroy`'s `destroyer` directly to `node_stream_core`'s `Stream.destroy`, which aborts unfinished streams with `AbortError` / `ABORT_ERR`), supplying the `ERR_*` constructors (including `RangeError` for `ERR_INVALID_ARG_VALUE` where `streams/iter` expects it), `aggregateTwoErrors`, and `AbortError` helpers also wired into `bun_builtins.ts`.
